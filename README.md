# My-timer
python/tkinterでの勉強用タイマー

## 1.プロジェクトについて
デスクトップアプリ開発の学習のために作成したポモドーロタイマー。

## 2.構成案
1. 終了間際に音を鳴らす -> winsound
2. 勉強時間を記録し、グラフに表示する
3. 小さいウィンドウに切り替える
4. 一番上に表示できる
5. 設定からテーマを変更できる

## 学習メモ
root.resizable(False, False)
(横幅, 縦幅)の変更制限

expand
Trueにすると、残っている領域を占有する

super()
親クラスを継承する

pacK()
fill: ウィジェットが空いているスペースを埋めるかどうか指定

tkinter.DISABLED
（ボタンウィジェット、state属性）ボタンの無効化、押せなくなる

tkinter.NORMAL
（ボタンウィジェット、state属性）ボタンの有効化
